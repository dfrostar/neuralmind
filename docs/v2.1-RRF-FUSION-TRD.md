## 1. Architecture Overview

### 1.1 What We Are Building

A dedicated module (`rerank_fusion.py`) implementing three-signal Reciprocal Rank Fusion, plus the wiring to integrate it into NeuralMind's existing `ContextSelector` pipeline. The current two-list `_rrf_merge` (hard-coded as a private method on `ContextSelector`, line 252) is replaced by a standalone, testable, configurable module that accepts N ranked lists and produces a single fused ranking.

The three ranked lists are:

| Signal | Source | Method | Return Shape |
|--------|--------|--------|-------------|
| **Dense** (vector) | ChromaDB via `GraphEmbedder.search()` | Cosine-distance similarity on MiniLM embeddings | `list[dict]` with `id`, `score`, `metadata` |
| **Sparse** (keyword) | BM25 index via `GraphEmbedder.bm25_search()` | TF-IDF–style term frequency scoring | `list[dict]` with `id`, `score`, `metadata` |
| **Graph** (synapse) | `SynapseStore` via `ContextSelector.synapse_recall()` | Spreading activation from seed hits | `list[tuple[node_id, energy]]` → converted to `list[dict]` |

### 1.2 Data Flow

```
agent query
    │
    ▼
ContextSelector.get_query_context()
    │
    ▼
ContextSelector._fetch_search(query, n=30)         ← NEURALMIND_RRF_MAX_N
    │
    ├── embedder.search(query, n=30)               ──► dense_results[30]
    ├── embedder.bm25_search(query, n=30)          ──► sparse_results[30]
    │
    ▼  (3rd signal: synapse)
    │
    ├── synapse_recall(seeds=[top_3_dense_ids])    ──► list[(node_id, energy)]
    │   └─► converted to synapse_results[30]
    │
    ▼
    │
    ├── NEURALMIND_RRF=0?  → old _rrf_merge(dense, sparse)       [backward compat]
    └── NEURALMIND_RRF=1?  → rrf_merge(dense, sparse, synapse)    [new three-signal]
        │
        ▼
    fused_results[30] → get_l3_search() → ...
```

**Key design:**
- The synapse spread is seeded from the **same top-3 dense hits** that `_apply_synapse_boost` uses today (line 645), ensuring the third signal's candidate pool is identical to what the existing code considers the most relevant.
- The three input lists are scored **independently by rank position only** — no score calibration, no distance-to-similarity conversion.
- The fused output is **budget-neutral** (max unique nodes ≤ sum of input list sizes), capped to `NEURALMIND_RRF_MAX_N`.

## 2. Algorithm Specification

### 2.1 Reciprocal Rank Fusion Formula

For each result item `d` present in any input ranked list `L`, the RRF score is:

```
RRF(d) = Σ_{L ∈ lists} 1 / (k + rank_L(d))
```

Where:
- `k` = the RRF constant (default 60, configurable via `NEURALMIND_RRF_K`)
- `rank_L(d)` = 1-based rank position of item `d` in list `L` (1 = first)
- Items not present in a given list contribute 0 from that list
- The final list is sorted descending by `RRF(d)`

**Normalisation:** The fused scores are normalised to `[0, 1]` by dividing through by the maximum score, so downstream consumers (L3 rendering, trace output) see a consistent score range.

### 2.2 Why k = 60

From Cormack et al. (SIGIR 2009): k = 60 was empirically optimal across TREC ad-hoc retrieval tasks. At k = 60, a rank-1 result contributes `1/61 ≈ 0.016`, while a rank-10 contributes `1/70 ≈ 0.014` — the top positions are slightly favoured but no single list dominates. Lower k (e.g., 30) makes the top of each list more influential; higher k (e.g., 100) flattens the curve. The env-var allows per-project tuning.

### 2.3 Tie-breaking

When two items have identical RRF scores, the item from the **dense** list wins (maintains the existing heuristic that vector similarity is the primary signal). If both items come from the same list, original rank order is preserved.

### 2.4 Pseudocode

```
def rrf_merge(*ranked_lists: list[dict], k: int = 60,
              max_n: int = 30) -> list[dict]:
    """
    Merge N ranked lists via Reciprocal Rank Fusion.

    Each list is a list of dicts, where each dict has at minimum an "id" key.
    Items within each list are ordered by descending relevance.
    """
    scores = {}      # id → accumulated RRF score
    by_id = {}       # id → first-seen result dict

    for lst_id, lst in enumerate(ranked_lists):
        for rank, item in enumerate(lst):
            item_id = item["id"]
            scores[item_id] = scores.get(item_id, 0.0) + 1.0 / (k + rank + 1)  # 1-based rank
            if item_id not in by_id:
                by_id[item_id] = item
            # Track which list contributed (for tie-breaking)
            by_id[item_id]["_rrf_list"] = by_id[item_id].get("_rrf_list", set()) | {lst_id}

    # Sort by descending RRF score; tie-break by dense-list priority
    max_score = max(scores.values()) if scores else 1.0
    ranked = sorted(
        scores.items(),
        key=lambda x: (-x[1], 0 not in by_id[x[0]].get("_rrf_list", set())),
    )

    results = []
    for item_id, rrf_score in ranked[:max_n]:
        node = dict(by_id[item_id])
        node["score"] = rrf_score / max_score      # Normalised [0, 1]
        node["_rrf_score"] = rrf_score              # Raw score (for trace/debug)
        node["_rrf_k"] = k                          # Which k produced this
        results.append(node)

    return results
```

## 3. Module Specification: rerank_fusion.py

### 3.1 Module Location

`neuralmind/rerank_fusion.py`

### 3.2 Public API

```python
def rrf_merge(*ranked_lists: list[dict[str, Any]],
              k: int = 60,
              max_n: int = 30) -> list[dict[str, Any]]:
    """
    Merge N ranked lists via Reciprocal Rank Fusion.

    Args:
        *ranked_lists: One or more lists of result dicts. Each dict must
            contain an ``id`` key. Items are ordered by descending relevance
            (best first) within each list.
        k: RRF constant (default 60). Must be >= 1.
        max_n: Maximum number of fused results to return (default 30).

    Returns:
        Fused list of dicts, sorted by descending RRF score. Each dict
        gains ``_rrf_score`` (raw RRF sum) and ``score`` (normalised [0,1]).
    """
```

### 3.3 Internal Types

```python
@dataclass
class RRFFusionResult:
    """Structured result from the RRF module for trace/debug output."""
    items: list[dict[str, Any]]
    rrf_k: int
    input_list_sizes: list[int]
    total_candidates: int
    """
```

### 3.4 Module-Level Constants

```python
# Default RRF constant (Cormack et al. standard)
RRF_K_DEFAULT = 60

# Minimum value for k
RRF_K_MIN = 1

# Default max candidates per input list
RRF_MAX_N_DEFAULT = 30
```

### 3.5 Edge Cases

| Input State | Behaviour |
|-------------|-----------|
| No lists provided | Return empty list |
| One list only | Return that list unchanged (no fusion needed) |
| Empty list(s) among inputs | Skip empty lists gracefully (they contribute 0) |
| Single item in all lists | RRF score = `N / (60 + 1)` where N = number of lists |
| Items with missing `id` | Skip; log warning once |
| k < 1 | Clamp to `RRF_K_MIN` (1) |
| max_n < 1 | Clamp to 1 |
| Duplicate IDs within one list | Keep last occurrence (the first-seen behaviour for tie-breaking) |

## 4. Integration Points

### 4.1 ContextSelector._fetch_search() — Primary Integration

**File:** `neuralmind/context_selector.py` (line ~309)

**Current behaviour (`NEURALMIND_RRF=0`):**
```python
vec_results = self.embedder.search(query, n=fetch_n)
bm25_search = getattr(self.embedder, "bm25_search", None)
if callable(bm25_search) and os.environ.get("NEURALMIND_BM25") != "0":
    kw_results = bm25_search(query, n=fetch_n)
    if kw_results and isinstance(kw_results, list):
        merged = self._rrf_merge(vec_results, kw_results)  # old 2-list path
        results = merged[:fetch_n]
```

**New behaviour (`NEURALMIND_RRF=1`):**
```python
from .rerank_fusion import rrf_merge

vec_results = self.embedder.search(query, n=fetch_n)
kw_results = []
syn_results = []

# Sparse signal
bm25_search = getattr(self.embedder, "bm25_search", None)
if callable(bm25_search) and os.environ.get("NEURALMIND_BM25") != "0":
    kw_results = bm25_search(query, n=fetch_n) or []

# Synapse signal (third list — graph-traversal energy)
if not self._synapse_disabled():
    seeds = [r["id"] for r in vec_results[:3] if r.get("id")]
    if seeds:
        try:
            syn_energy = dict(self.synapse_recall(seeds))
            # Convert energy dict → ranked list of dicts
            syn_sorted = sorted(syn_energy.items(), key=lambda x: -x[1])
            syn_results = [
                {"id": nid, "score": e, "_rrf_signal": "synapse"}
                for nid, e in syn_sorted[:fetch_n]
            ]
        except Exception:
            pass

rrf_k = int(os.environ.get("NEURALMIND_RRF_K", "60"))
rrf_max_n = int(os.environ.get("NEURALMIND_RRF_MAX_N", "30"))
fetch_candidates = max(rrf_max_n, self._query_search_max_n)

merged = rrf_merge(vec_results, kw_results, syn_results,
                   k=rrf_k, max_n=fetch_candidates)
results = merged[:fetch_n]
```

### 4.2 ContextSelector.RRF_K — Deprecation Path

The existing `RRF_K = 60` class constant and `_rrf_merge` method are **kept as-is** for the duration of v2.1. A deprecated docstring is added:

```python
# RRF constant — DEPRECATED in favour of neuralmind/rerank_fusion.py
# and the NEURALMIND_RRF_K env var. Kept for backward compatibility
# when NEURALMIND_RRF=0 (default).

```

Removal target: v2.2, pending verification that no external code calls `ContextSelector._rrf_merge()`.

### 4.3 NeuralMind.build() — Config Threading

**File:** `neuralmind/core.py` (around line ~493, where `ContextSelector` is constructed)

No constructor changes required — `_fetch_search` reads env vars directly (matching the pattern of `NEURALMIND_BM25` and `NEURALMIND_SYNAPSE_INJECT`).

### 4.4 Embedder — No Changes Required

Both `search()` (line 370) and `bm25_search()` (line 628) already return `list[dict]` with `id`, `score`, and `metadata` fields — the exact input shape `rrf_merge` expects. The synapse signal is constructed on the fly from the existing `synapse_recall` callable (line 222), which also already exists.

## 7. Performance Impact

### 7.1 Computational Complexity

RRF is O(N) where N = total items across all input lists, dominated by:

1. **Iteration over each list** — O(Σ|L_i|) to accumulate scores in a hash map
2. **Sorting the merged results** — O(M log M) where M = unique IDs across all lists
3. **Normalisation** — O(M)

For the expected case (3 lists × 30 items each = 90 items, ~50 unique IDs), total work is dominated by sorting ~50 items — effectively instant. No vector operations, no model inference.

### 7.2 Latency Budget

| Stage | Baseline (RRF=0) | RRF=1 (worst case) |
|-------|-----------------|-------------------|
| Dense search (ChromaDB) | 5–50 ms | 5–50 ms |
| BM25 search | < 1 ms | < 1 ms |
| Synapse spread from seeds | < 1 ms | < 1 ms |
| **RRF merge** | **0 ms** | **< 0.1 ms** (3 × 30 items) |
| **Total added latency** | — | **< 1 ms** |

The latency overhead of RRF is negligible relative to the ChromaDB query time (the dominant term).

### 7.3 Memory Impact

- Input lists: ~90 dict objects × ~200 bytes ≈ 18 KB
- Scores/IDs hash map: ~50 entries × ~100 bytes ≈ 5 KB
- Output list: ~30 dict objects with fused fields ≈ 8 KB
- **Total: ~31 KB per query** — well within any reasonable memory budget.

## 9. Error Handling & Graceful Degradation

| Failure Mode | Degradation Path |
|-------------|-----------------|
| `synapse_recall` is None (cold graph) | RRF degrades to two-list (dense + sparse). If only one list, identity-path returns it unchanged. |
| `bm25_search()` throws | kw_results = [], degrade to two-list (dense + synapse) |
| `embedder.search()` fails | Results = [] → RRF returns `[]`. Query returns no results (same as today if the embedder fails). |
| `NEURALMIND_RRF_K` env var unparseable | Fall back to `RRF_K_DEFAULT = 60`. Log a warning once. |
| Env-var race (process set mid-query) | Toggle takes effect on next `_fetch_search` call; mid-query consistency is maintained. |
| Memory exhaustion on large lists | The merge caps at `max_n`; list sizes are bounded by `NEURALMIND_RRF_MAX_N` (default 30). No unbounded growth path exists. |

## Appendix A: Comparison of Old vs New RRF Path

| Aspect | Old `_rrf_merge` (line 252) | New `rrf_merge` (rerank_fusion.py) |
|--------|---------------------------|-------------------------------------|
| Inputs | Exactly 2 (vec, kw) | N (variadic); wired for 3 (dense, sparse, synapse) |
| k constant | `RRF_K = 60` (class constant) | `k` parameter (env-var tunable) |
| Location | Private method on `ContextSelector` | Standalone module function |
| Normalisation | `score = rrf / max_score` | Same (preserved) |
| Tie-breaking | Implicit (dict insertion order) | Explicit: dense-list item wins |
| `_rrf_score` field | Not emitted | Emitted on all output items |
| Test coverage | Integration-only | 14 unit tests + 3 integration tests |
| Signal tracing | None | `_rrf_signal` on synapse-originated items |
