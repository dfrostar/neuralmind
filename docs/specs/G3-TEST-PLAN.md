## 4. Effectiveness Measurement

### Before G3 (per-file):
Every file is its own community. For a project with 50 files → 50 communities.
No grouping at all — L2 retrieval gets maximal coverage but low precision (all communities equally salient).

### After G3 (Louvain):
Depends on actual dependency structure. For a typical medium project:
- Expected: 3..8 communities (grouped by architectural layer)
- L2 retrieval focuses on communities with strongest query edges

### Measurement command:
```bash
python3 -c "
import json
g = json.load(open('graphify-out/graph.json'))
communities = {}
for n in g['nodes']:
    if n['file_type'] == 'code':
        communities.setdefault(n['community'], []).append(n['source_file'])
for c, files in sorted(communities.items()):
    print(f'Community {c}: {sorted(set(files))}')
"
```
