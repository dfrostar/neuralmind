## 4. Technical Specifications

### 4.1 Evidence Collection Script

```python
#!/usr/bin/env python3
"""
Vanta evidence collection script for NeuralMind.
Run weekly via GitHub Actions to collect application-specific evidence.
"""

import json
import subprocess
import sys
from datetime import datetime, timezone
from pathlib import Path

def collect_health_evidence():
    """Collect /healthz endpoint response."""
    try:
        result = subprocess.run(
            ["curl", "-s", "http://localhost:8080/healthz"],
            capture_output=True, text=True, timeout=10
        )
        return {
            "timestamp": datetime.now(timezone.utc).isoformat(),
            "endpoint": "/healthz",
            "status": "healthy" if result.returncode == 0 else "unhealthy",
            "response": result.stdout if result.returncode == 0 else result.stderr
        }
    except Exception as e:
        return {
            "timestamp": datetime.now(timezone.utc).isoformat(),
            "endpoint": "/healthz",
            "status": "error",
            "error": str(e)
        }

def collect_audit_log_summary():
    """Collect summary of audit_events.jsonl."""
    audit_path = Path(".neuralmind/audit_events.jsonl")
    if not audit_path.exists():
        return {"status": "no_audit_log"}
    
    lines = audit_path.read_text().strip().split("\n")
    events = [json.loads(line) for line in lines if line.strip()]
    
    return {
        "timestamp": datetime.now(timezone.utc).isoformat(),
        "total_events": len(events),
        "date_range": {
            "first": events[0].get("timestamp") if events else None,
            "last": events[-1].get("timestamp") if events else None
        },
        "actors": list(set(e.get("actor") for e in events)),
        "actions": list(set(e.get("action") for e in events))
    }

def collect_index_integrity():
    """Collect index validation results."""
    try:
        result = subprocess.run(
            ["neuralmind", "build", ".", "--verify"],
            capture_output=True, text=True, timeout=300
        )
        return {
            "timestamp": datetime.now(timezone.utc).isoformat(),
            "command": "neuralmind build . --verify",
            "status": "valid" if result.returncode == 0 else "invalid",
            "output": result.stdout[-1000:] if result.stdout else ""
        }
    except Exception as e:
        return {
            "timestamp": datetime.now(timezone.utc).isoformat(),
            "status": "error",
            "error": str(e)
        }

def main():
    evidence = {
        "collection_timestamp": datetime.now(timezone.utc).isoformat(),
        "health": collect_health_evidence(),
        "audit_log": collect_audit_log_summary(),
        "index_integrity": collect_index_integrity()
    }
    
    output_path = Path("evidence") / f"{datetime.now().strftime('%Y-%m-%d')}.json"
    output_path.parent.mkdir(exist_ok=True)
    output_path.write_text(json.dumps(evidence, indent=2))
    
    print(json.dumps(evidence, indent=2))
    return 0

if __name__ == "__main__":
    sys.exit(main())
```

### 4.2 Health Check Monitor Workflow

```yaml
# .github/workflows/monitor.yml
name: Health Check Monitor

on:
  schedule:
    - cron: '0 */6 * * *'  # Every 6 hours
  workflow_dispatch:

jobs:
  health-check:
    runs-on: ubuntu-latest
    steps:
      - name: Check health endpoint
        run: |
          curl -sf http://localhost:8080/healthz || echo "Health check failed"
      
      - name: Collect evidence
        run: python scripts/collect-evidence.py
      
      - name: Upload evidence
        uses: actions/upload-artifact@v4
        with:
          name: compliance-evidence-${{ github.run_id }}
          path: evidence/
          retention-days: 90
```

### 4.3 Backup Test Script

```bash
#!/bin/bash
# scripts/backup-test.sh
# Tests backup and recovery of NeuralMind data

set -e

BACKUP_DIR=$(mktemp -d)
PROJECT_DIR=$(pwd)

echo "=== NeuralMind Backup Test ==="
echo "Date: $(date -u +%Y-%m-%dT%H:%M:%SZ)"
echo "Backup directory: $BACKUP_DIR"

# Backup
echo "Creating backup..."
cp -r .neuralmind "$BACKUP_DIR/" 2>/dev/null || true
cp -r graphify-out "$BACKUP_DIR/" 2>/dev/null || true

# Verify backup integrity
echo "Verifying backup..."
if [ -d "$BACKUP_DIR/.neuralmind" ]; then
    echo "✓ .neuralmind backed up"
else
    echo "✗ .neuralmind backup failed"
    exit 1
fi

# Simulate recovery
echo "Simulating recovery..."
RECOVERY_DIR=$(mktemp -d)
cp -r "$BACKUP_DIR/.neuralmind" "$RECOVERY_DIR/"

# Verify recovery
if [ -d "$RECOVERY_DIR/.neuralmind" ]; then
    echo "✓ Recovery successful"
else
    echo "✗ Recovery failed"
    exit 1
fi

# Cleanup
rm -rf "$BACKUP_DIR" "$RECOVERY_DIR"

echo "=== Backup test PASSED ==="
```

## 6. Security Considerations

### 6.1 Evidence Storage

- Evidence artifacts stored in `evidence/` directory (gitignored)
- Artifacts uploaded to GitHub Actions artifacts (90-day retention)
- Long-term storage: Vanta platform retains evidence for audit period

### 6.2 Access Control

- Only maintainers can trigger evidence collection
- Evidence artifacts contain no sensitive data (counts, timestamps, statuses)
- Audit log summaries contain actor names but no PII

### 6.3 Data Retention

- Evidence retained for 7 years (audit standard)
- Local evidence: 90 days in GitHub Actions artifacts
- Vanta evidence: retained per Vanta's retention policy
