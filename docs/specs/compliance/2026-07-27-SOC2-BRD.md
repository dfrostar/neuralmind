## 1. Business Requirements

### 1.1 Problem Statement

NeuralMind has no formal SOC 2 compliance posture. Enterprise prospects (10+ seats, regulated industries) increasingly require SOC 2 Type II reports before procurement. The current compliance documentation (`COMPLIANCE-SUMMARY.md`, `SECURITY.md`) maps controls but has never been validated by an auditor.

### 1.2 Success Criteria

| ID | Criteria | Verification |
|----|----------|-------------|
| BR-01 | SOC 2 Type II readiness package complete | All 5 Trust Service Criteria documented with evidence |
| BR-02 | Vanta (or equivalent) engagement scoped | Vendor selected, timeline committed, budget approved |
| BR-03 | Readiness gap assessment completed | Gap report with remediation plan |
| BR-04 | Operating period started | Controls in place and operating for ≥ 2 fiscal quarters |
| BR-05 | Auditor engagement letter signed | External audit firm contracted |

### 1.3 Constraints

- Solo maintainer — no dedicated compliance FTE
- Budget: $5K-$15K/yr for Vanta + auditor fees ($10K-$25K for Type II audit)
- Timeline: 6-12 months from initiation to audit opinion
- MIT open-source model — no revenue to amortize costs yet

### 1.4 Non-Goals

- HIPAA / PCI DSS / FedRAMP certification (future phases)
- Automated compliance monitoring (manual evidence collection acceptable for v1)
- SOC 2 Type I (snapshot) — Type II (operating effectiveness) is the enterprise requirement

## 3. Vanta Engagement Plan

### 3.1 Vendor Selection

| Vendor | Type | Cost | Pros | Cons |
|--------|------|------|------|------|
| **Vanta** | Automated compliance platform | ~$5K-$10K/yr | Gold standard, continuous monitoring, evidence automation | Annual contract, requires dedicated time |
| Drata | Automated compliance platform | ~$5K-$10K/yr | Similar to Vanta, strong UX | Same cost, less brand recognition |
| Secureframe | Automated compliance platform | ~$5K-$10K/yr | Good for startups | Same cost |
| Manual (spreadsheets) | Self-managed | $0 + auditor time | No platform cost | High manual burden, error-prone |

### 3.2 Recommended Approach: Vanta

**Why:** The user already has CI/CD, GitHub, Cloudflare, and structured logging. Vanta integrates with all of these and automates 60-70% of evidence collection. For a solo maintainer, automation is essential.

**Timeline:**

| Phase | Duration | Activities |
|-------|----------|------------|
| **Engagement** | Week 1-2 | Sign Vanta contract, connect integrations (GitHub, Cloudflare, AWS if any) |
| **Gap Assessment** | Week 3-4 | Vanta scans environment, identifies gaps, generates remediation tasks |
| **Remediation** | Month 2-3 | Close gaps: access reviews, change management, incident response, risk assessment |
| **Operating Period** | Month 4-9 | Controls operate, evidence accumulates, Vanta monitors continuously |
| **Auditor Selection** | Month 3-4 | Engage external audit firm (Vanta has partner network) |
| **Readiness Review** | Month 8-9 | Pre-audit walkthrough, evidence package review |
| **Audit** | Month 10-12 | External auditor tests controls, issues opinion |
