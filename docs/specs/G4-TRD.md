## 1. Scope

Wire `IncrementalExtractor` into `build_graph()` so unchanged files skip re-extraction. Reverse-edge invalidation via `importer_index.json`. Dangling-edge prune when nodes are removed/renamed.

## 2. Architecture

```
build_graph(project_path):
  IncrementalExtractor(root)
  load_importer_index(root)         # persisted from previous build
  Load .neuralmind/extraction_cache.json
  Load graphify-out/graph.json (existing_graph)

  # Determine what to re-extract
  if extraction_cache exists:
    changed = extractor.scan_files(root, suffixes)         # added/modified/deleted
    changed_with_dep = extractor.get_changed_with_dependents(root, suffixes, importer_index)
    re_extract_set = changed_with_dep                   # transitive importers included
  else:
    re_extract_set = all files                         # first build

  # Reuse unchanged nodes/edges from existing_graph
  if existing_graph AND cache:
    for node in existing_graph["nodes"]:
      if node.source_file not in re_extract_set:
        b.nodes[node.id] = node                       # reuse (no re-extraction)
    surviving_ids = {n.id for n in reused nodes}
    for edge in existing_graph["links"]:
      if edge.source_file in re_extract_set: skip      # re-derive
      if edge.source not in surviving_ids: skip        # dangling prune
      if edge.target not in surviving_ids: skip        # dangling prune
      b.edges.append(edge)                            # preserve
  else:
    full extraction, all files

  # Re-extract changed files only
  for fpath in files where rel in re_extract_set:
    two-pass extraction (symbols + edges)

  _assign_communities(b, existing_graph)                # G3 carry-over

  extractor.update_cache(re_extract_set)
  save_importer_index(root, build_importer_index_from_graph(b.graph))
```

### Key Invariants

- `importer_index.json` must be rebuilt every build (outdated index = missed invalidations)
- `extraction_cache.json` persists only content hash + mtime (no symbol metadata)
- `community` IDs carried from existing_graph via `_assign_communities` (G3 invariant preserved)
- Dangling edges dropped: any edge whose source or target node no longer exists in `b.nodes` is skipped

## 3. Complexity

| Component | Complexity | Notes |
|-----------|-----------|-------|
| `scan_files()` | O(n + m) | n source files, m cache entries |
| `build_importer_index_from_graph()` | O(n + E) | single pass over nodes + edges |
| `get_changed_with_dependents()` | O(k + d) | k changed files, d transitive importers |
| Incremental `build_graph()` | O(Δ + Δ_importers) | Δ = changed files, not n |
| Full `build_graph()` | O(n + m) | same as before |

Performance target: Δ << n on typical dev cycle → 10× speedup expected.
