# Visual Prompt — NeuralMind Marketing Hero Image

## Prompt (for Midjourney / DALL-E / Ideogram)

```
A minimalist technical illustration of a neural network graph fused with a code repository structure. Clean, dark background (#0B0F19) with electric blue (#3B82F6) and proton purple (#8B5CF6) accent nodes. The graph shows interconnected code symbols (braces, semicolons, function nodes) linked by glowing synaptic edges. Some nodes pulse brighter than others — representing Hebbian reinforcement. A subtle lock icon sits in the bottom-right corner, signaling local-first security. No text. No photorealism. Flat vector style with subtle gradients, similar to Vercel or Linear marketing illustrations. Aspect ratio 16:9.
```

## Style Guide

- **Colors:** Background `#0B0F19`, Electric `#3B82F6`, Proton `#8B5CF6`, Iris `#6366F1`
- **No text in image** — let the site UI handle typography
- **No photorealism** — flat vector with subtle gradients
- **No human faces** — pure abstraction
- **Subtle lock motif** — reinforces "local-first" positioning
