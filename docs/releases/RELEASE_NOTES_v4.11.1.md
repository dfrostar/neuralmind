# NeuralMind v4.11.1 — not released

There was no v4.11.1 release. v4.11.0 was followed by **v4.12.0**, which ships
the change these notes described: `neuralmind build` and `neuralmind doctor`
no longer open a turbovec store on a project whose backend isn't turbovec.
See [v4.12.0: no turbovec store on a ChromaDB project](RELEASE_NOTES_v4.12.0.md#also-in-this-release-no-turbovec-store-on-a-chromadb-project).

Where v4.12.0's measurements compare against "v4.11.1", they mean `main` just
before v4.12.0's retrieval change (#622): v4.11.0 plus #612 and #619, neither of
which changes retrieval.
