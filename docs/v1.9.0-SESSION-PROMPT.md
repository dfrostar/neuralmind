### B. Payment Broker Pattern (~60 min)

**Goal:** Pluggable payment provider interface (Stripe primary, LemonSqueezy fallback).

**Current state:**
- Autopilot has `StripeClient` + `StripeWebhookHandler` + `LicensingManager(provider="stripe")`
- NeuralMind has NO payment code (only license validation)
- Grace period is currently global (`SelfHostedConfig.offline_grace_days`)

**Architecture:**
```
neuralmind/tier2/
├── payment/
│   ├── __init__.py          # PaymentProvider ABC
│   ├── stripe_provider.py   # Stripe implementation
│   ├── lemonsqueezy.py      # LemonSqueezy implementation (stub)
│   └── exceptions.py        # PaymentError hierarchy
```

**Key principle:** NeuralMind defines the interface; Autopilot implements the live calls. This avoids duplicating payment logic and keeps NeuralMind testable without Stripe credentials.

**Files:**
- `neuralmind/tier2/payment/__init__.py` (NEW — ABC)
- `neuralmind/tier2/payment/stripe_provider.py` (NEW — Stripe impl)
- `neuralmind/tier2/payment/lemonsqueezy.py` (NEW — LemonSqueezy stub)
- `neuralmind/tier2/payment/exceptions.py` (NEW)
- `tests/test_payment_providers.py` (NEW — unit tests)

**PaymentProvider ABC:**
```python
class PaymentProvider(ABC):
    @abstractmethod
    def create_subscription(self, customer_email: str, seats: int, ...) -> dict: ...
    
    @abstractmethod
    def cancel_subscription(self, subscription_id: str) -> dict: ...
    
    @abstractmethod
    def verify_webhook(self, payload: bytes, sig_header: str) -> dict: ...
    
    @abstractmethod
    def get_subscription_status(self, subscription_id: str) -> str: ...  # active/past_due/canceled
```

**StripeProvider:**
- Wraps `autopilot.stripe_client.StripeClient` (or reimplements minimally)
- Maps Stripe subscription statuses to NeuralMind license states
- Verifies webhook signatures with `stripe.Webhook.construct_event()`

**LemonSqueezyProvider:**
- Stub with `NotImplementedError` for now
- Placeholder for future implementation
- Raises `PaymentProviderError("LemonSqueezy not yet implemented")`

**Tests:**

### C. Grace Period Per-License (~45 min)

**Goal:** Make offline grace period configurable per-customer instead of global.

**Current state:**
- `SelfHostedConfig.offline_grace_days` = 30 (global)
- `LicenseValidator._is_within_grace()` reads `getattr(self, "offline_grace_days", 30)`

**Problem:** Enterprise customers need different grace periods (e.g., 90 days for air-gapped, 7 days for cloud).

**Files:**
- `neuralmind/tier2/license.py` — Modify `LicenseValidator` to accept per-license grace
- `neuralmind/tier2/config.py` — Add `license_grace_days` field to `Tier2Config`
- `tests/test_license_grace.py` (NEW)

**Design:**
1. Add `license_grace_days: int = 30` to `Tier2Config` (global default)
2. Modify `LicenseValidator.__init__` to accept optional `grace_days: int | None = None`
3. If `grace_days` is None, fall back to `config.license_grace_days`
4. License JSON can include `grace_days` field for per-customer override
5. `issue_license()` accepts `grace_days` parameter

**Key changes in `license.py`:**
```python
class LicenseValidator:
    def __init__(
        self,
        public_key_hex: str,
        license_path: Path,
        anti_tamper: Any = None,
        grace_days: int | None = None,  # NEW: per-instance override
    ):
        ...
        self._grace_days = grace_days

def issue_free_license(path: Path, grace_days: int | None = None) -> LicenseInfo:
    ...

def issue_team_license(
    path: Path,
    customer_email: str,
    company: str,
    seats: int,
    duration_days: int,
    grace_days: int | None = None,  # NEW

    ...
```

## BEST PRACTICES (from Waves 1–17)

1. **Always trace the end-to-end journey before shipping.** Wave 14 built 4 modules that worked in isolation but didn't connect.
2. **Default values are promises.** Every default should be the free/no-privilege path.
3. **First-run identity is not optional.** A product with tiers must provision identity on first meaningful action.
4. **Gaps are ship-blockers.** If the gap trace finds something the user/operator needs but the code/docs don't deliver, fill it before tagging.
5. **Atomic writes for concurrency-sensitive paths.** Use `tempfile.mkstemp()` + `Path.replace()` — not `write_text()`.
6. **--json output must never be contaminated** with human-readable prints.
7. **Both promote and rollback must invoke ship_callable.** Asymmetry breaks the loop.
8. **Read delta, not verdict.** The `verdict` column is local computation; `delta` drives the global decision.
9. **Fail-open on all external subprocess calls.** A single failed benchmark must not halt the tick.
10. **Honest data-quality labels on every number.** `measured`, `synthetic`, or `modeled` — no exceptions.
11. **Marketing audit is mandatory per release.** All 9 surfaces, every time.
12. **Claim-tier every claim.** A/B/C/D taxonomy, no Tier D as fact.
13. **Email everything in the body.** AgentMail has no attachment channel.
14. **Browser-verify the dashboard.** `curl 200` ≠ UI works.
15. **Pure Python, stdlib-only for new algorithms.** No NetworkX, no heavy deps.

## PITFALLS (do not re-learn the hard way)

1. **`init_db` hazard** — `PromotionEngine` + `ExperimentRunner` never call `init_db`; tests must call it explicitly (from autopilot, but check if porting)
2. **Connection close** — every `get_db()` in `try/finally: conn.close()`
3. **Penny clamp** — `round(budget, 2)` collapses to 0.00 on small budgets
4. **AVG(baseline) not AVG(value)** — learn from baseline column, not value
5. **NaN/Inf guard** — `var_d <= 0` misses NaN; use `not math.isfinite(var_d)`
6. **chromadb optional** — guard test modules with `pytest.importorskip("chromadb")`
7. **ruff format vs black** — repo has BOTH `[tool.black]` (line-length=100) and `[tool.ruff]`. They disagree on wrapping at same line-length. Resolution: `black .` first → `ruff format .` second. See `formatter-gate` skill.
8. **Version sync** — tag, `__version__`, `pyproject.toml` must match before push
9. **Hermes verify** — inline `python3 -c` does NOT satisfy Hermes verification gate. Temp script in `/tmp/hermes-verify-*.py` + test run IS required.
