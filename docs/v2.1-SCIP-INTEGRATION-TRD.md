```
│                            └────────────────────┘               │

│  │ scip_backend.py     │   (config facade)                       │

│  │ ScipBackend         │   wraps precision.py                     │
│  └────────────────────┘                                           │
└──────────────────────────────────────────────────────────────────┘
```

### Data Flow

1. `graphgen.build_graph()` produces a complete graph.json with heuristic edges.
2. `core._maybe_generate_builtin_graph()` calls `precision.maybe_refine()` after the tree-sitter graph is built.
3. `maybe_refine()` checks `NEURALMIND_PRECISION` env var → if disabled, returns graph unchanged.
4. If enabled, calls `find_scip_index()` to locate a `*.scip` file.
5. If found, calls `parse_scip_index()` (protobuf wire decoder) → returns `ScipIndex` dataclass tree.
6. Calls `refine_graph(graph, index)` → replaces heuristic `calls`/`inherits` edges for covered files with SCIP-precise edges.
7. Returns `(graph, stats)` — stats printed to stderr; graph written to `graphify-out/graph.json`.

## 2. SCIP Data Format Ingestion

### 2.1 Protobuf Wire Decoder

The SCIP index is a serialized protobuf `Index` message (fields defined in `scip.proto` at github.com/scip-code/scip). Rather than requiring the `protobuf` Python runtime, `precision.py` implements a **minimal wire-format reader** that only decodes the fields needed for edge resolution.

**Wire type support:**
- `VARINT` (0) — for field numbers, symbol_roles, packed int32 ranges
- `LENGTH_DELIMITED` (2) — for string symbol names, embedded sub-messages
- `32BIT` (5) — for fixed32 fields (unused by SCIP but decoded for completeness)

**Fields decoded from SCIP Index message:**

| Field # | Name | Type | Usage |
|---------|------|------|-------|
| `2` | `documents` | `repeated Document` | Per-file occurrences and symbols |

**Per Document:**
| Field # | Name | Type | Usage |
|---------|------|------|-------|
| `1` | `relative_path` | `string` | File path relative to project root |
| `2` | `occurrences` | `repeated Occurrence` | Each symbol usage (def or ref) |
| `3` | `symbols` | `repeated SymbolInformation` | Per-symbol relationships |

**Per Occurrence:**
| Field # | Name | Type | Usage |
|---------|------|------|-------|
| `1` | `range` | `repeated int32` | `[startLine, startChar, endLine, endChar]` |
| `2` | `symbol` | `string` | Fully-qualified SCIP symbol string |
| `3` | `symbol_roles` | `int32` | Bitmask: bit 0 = definition, 0 = reference |
| `7` | `enclosing_range` | `repeated int32` | Function/class body range containing this occurrence |

**Per SymbolInformation:**
| Field # | Name | Type | Usage |
|---------|------|------|-------|
| `1` | `symbol` | `string` | SCIP symbol string |
| `4` | `relationships` | `repeated Relationship` | Inherits/implementation links |

**Per Relationship:**
| Field # | Name | Type | Usage |
|---------|------|------|-------|
| `1` | `symbol` | `string` | The base/parent symbol |
| `3` | `is_implementation` | `bool` | True when this symbol implements/extends the base |

### 2.2 SCIP Model Dataclasses

```python
@dataclass
class ScipOccurrence:
    range: list[int]            # [startLine, startChar, endLine, endChar]
    symbol: str                 # e.g. "scip-python python . . app/A#handle()."
    symbol_roles: int           # 0x1 = definition, 0x0 = reference
    enclosing_range: list[int]  # Body range of enclosing function

@dataclass
class ScipRelationship:
    symbol: str                 # Base/parent symbol
    is_implementation: bool     # True for extends/implements

@dataclass
class ScipSymbol:
    symbol: str
    relationships: list[ScipRelationship]

@dataclass
class ScipDocument:
    relative_path: str
    occurrences: list[ScipOccurrence]
    symbols: list[ScipSymbol]

@dataclass
class ScipIndex:
    documents: list[ScipDocument]
```

### 2.4 Edge Cases

| Scenario | Behavior |
|----------|----------|
| No `*.scip` file found | Return graph unchanged; stats=None |
| Malformed protobuf (truncated, corrupted) | Catch Exception; log warning; return graph unchanged |
| Empty SCIP index (0 documents) | Return graph unchanged |
| SCIP references symbol not in graph | Silently skip (no dangling edges) |
| SCIP file > 50MB | Log size warning; parse anyway (may be slow) |
| Two indexers produce different symbol strings | Symbol parser handles both `#method` and `/method` patterns |

## 3. Merge Strategy: SCIP Edges + Tree-Sitter Nodes

### 3.1 The Principle

**Tree-sitter owns the nodes; SCIP owns the edges.** The SCIP pass only modifies `edges[].relation`, `edges[].confidence`, and the `graph["precision"]` marker. Nodes, communities, and non-call/inherit edges (`contains`, `imports_from`, `rationale_for`, `describes`, `maps_to`) are preserved byte-for-byte.

### 3.2 Step-by-Step Refinement

```
refine_graph(graph, index):
  1. Build node lookup: node_by_id, parent_of (from contains edges)
  2. Build symbol-to-node index: by_key[(source_file, enclosing_type, name)] → node_id
  3. Collect set of covered_files from index documents
  4. Build sym_def: global SCIP symbol → graph node id (from definitions)
  5. For each document:
     a. Collect fn_defs (definition occurrences of callables with known sym_def)
     b. For each reference occurrence:
        - Skip if definition or non-callable
        - Look up callee in sym_def
        - Find enclosing function via range containment
        - If caller found and caller ≠ callee: emit PRECISE calls edge
     c. For each symbol's relationships:
        - If is_implementation: emit PRECISE inherits edge
  6. Filter: keep only non-call/inherit edges for covered files ← these are from tree-sitter
  7. Deduplicate SCIP edges by (relation, source, target)
  8. Concatenate: kept tree-sitter edges + deduped SCIP edges
  9. Set graph["precision"] = "scip"
 10. Return (graph, stats)
```

### 3.3 Symbol → Node Resolution

SCIP symbols look like:
```
scip-python python . . app/AuthService#handle().  
#                    └────────┬────────┘ └──┬──┘└──┘
#                      path descriptor   name  callable()
```

The `_parse_descriptor()` function extracts `(enclosing_type, name, is_callable)`:

```python
def _parse_descriptor(symbol: str) -> tuple[str | None, str, bool]:
    """
    'scip-python python . . app/AuthService#handle().'
      → ('AuthService', 'handle', True)

    'scip-python python . . app/User#.'
      → (None, 'User', False)   [User is a class, not callable]

    'scip-typescript typescript . . src/auth#.'
      → (None, 'auth', False)   [module-level export]
    """
```

Resolution uses a key-based lookup:

```python
by_key[(source_file, enclosing_type, name)] → node_id
```

This is class-aware: `handle()` in `AuthService` resolves to `auth_service__handle_fn`, not to `user_service__handle_fn`. The enclosing type is recovered from the `contains` edge parent chain.

### 3.4 Edge Confidence Markers

| Source | Edge `confidence` Field | `confidence_score` Field |
|--------|------------------------|--------------------------|
| Tree-sitter (heuristic) | `"EXTRACTED"` | `1.0` |
| SCIP (compiler-accurate) | `"PRECISE"` | `1.0` |
| Dynamic import resolved | `"EXTRACTED"` | `< 1.0` (per confidence score) |

### 4.1 Environment Variable

```bash
# Enable SCIP precision (require *.scip index in project root)
export NEURALMIND_PRECISION=1

unset NEURALMIND_PRECISION

export NEURALMIND_PRECISION=false
```

## 5. Schema Changes

### 5.1 `graph.json` Additions

| Field | Type | Always Present? | Description |
|-------|------|-----------------|-------------|
| `graph["precision"]` | `string` | Only when SCIP pass ran | `"scip"` when edges were refined |
| `edges[].confidence` | `string` | Yes | New value: `"PRECISE"` for SCIP-resolved edges alongside existing `"EXTRACTED"` |
| `edges[].context` | `string` | Yes | Updated: `"calls (scip)"` or `"inherits (scip)"` vs `"calls"` / `"inherits"` |

### 5.2 No Schema Changes to Nodes

The SCIP pass does not add, remove, or modify nodes. All node fields (`id`, `label`, `file_type`, `source_file`, `source_location`, `community`, `norm_label`) are preserved from the tree-sitter pass.

### 5.3 No `.neuralmind/` Artifact Changes

| Artifact | Impact | Rationale |
|----------|--------|-----------|
| `.neuralmind/index_ir.json` | None | IR is recomputed from `graph.json`; PRECISE edges flow through |
| `.neuralmind/ir_meta.json` | None | State summary unchanged |
| `.neuralmind/synapses.db` | None | Synapse store operates on edges regardless of source |
| `.neuralmind/ci-baseline.json` | None | CI baseline uses final graph |
| `graphify-out/graph.json` | Updated | Precision pass writes refined edges |

### 5.4 Graph Version Semantics

`SCHEMA_VERSION` in `graphgen.py` stays at `2` — this is a runtime enhancement, not a schema change. The `generated_by` field remains `"neuralmind.graphgen (tree-sitter)"` since the graph is still produced by the tree-sitter backend; SCIP is an edge-level refinement. The `graph["precision"]` marker serves as a runtime metadata field for downstream consumers that care about edge provenance.

## 8. Performance Considerations

| Concern | Measurement | Mitigation |
|---------|-------------|------------|
| SCIP file size | Typical: 1–50MB for 10K-file project | Parse in streaming mode (future); for v2.1, warn if >50MB |
| parse_scip_index() time | ~0.5 sec/MB on modern hardware | Acceptable — runs once per build, not per query |
| refine_graph() time | ~0.3 sec per 100K occurrences | Linear scan; acceptable for v2.1 |
| Memory for parsed ScipIndex | ~5x wire size | Acceptable for 50MB index (~250MB peak) |
| Graph.json write overhead | +1 field `confidence_score` per edge | Negligible |

**Target:**
- Build-time overhead: < 2 seconds added to `neuralmind build` for a 10K-file codebase with SCIP index
- No impact on query-time performance (edges are structural, not query-derived)

1. **Should we bundle `scip-cli` as an optional dependency?** Currently the user must install `scip-cli` separately. We could add a `neuralmind scip-index` convenience command that shells out to `npx scip-cli ...`. Decision: defer to v2.2.

2. **Should we add SCIP index generation to `neuralmind init`?** The init flow could auto-detect language and run the appropriate SCIP indexer. This would make the feature zero-config. Decision: defer to v2.2.

3. **Python SCIP index support.** `scip-python` exists but is less mature than tree-sitter for Python. For v2.1, Python remains tree-sitter-primary; SCIP Python support is experimental/untested.

4. **Cross-repo SCIP merging.** A multi-repo project (G6) could merge indexes from each repo. This is a natural extension but requires workspace-level merge logic. Decision: defer to v2.2+.

5. **Clippy-style LSP integration.** A future backend could use LSP's `textDocument/references` for real-time resolution in the watcher path. However, LSP requires running language servers per-file-type, which is operationally complex. SCIP is the right batch-oriented solution.

## Appendix A: Protobuf Wire Decoder Reference

The minimal protobuf decoder in `precision.py` reads the SCIP protobuf without any runtime dependency. For reference:

```python
# Wire types as defined by Protocol Buffers
_WT_VARINT = 0    # int32, int64, uint32, uint64, sint32, sint64, bool, enum
_WT_64BIT = 1     # fixed64, sfixed64, double
_WT_LEN   = 2     # string, bytes, embedded messages, packed repeated fields
_WT_32BIT = 5     # fixed32, sfixed32, float

# Tag = (field_number << 3) | wire_type
def _read_varint(buf, pos) -> (int, int): ...
def _iter_fields(buf) -> (field_number, wire_type, value): ...
```

SCIP uses:
- Field 2 (documents) = length-delimited repeated `Document` messages
- Field 1 (relative_path) = length-delimited string
- Field 1 (range) = packed varints (repeated int32)
- Field 2 (symbol) = length-delimited string
- Field 3 (symbol_roles) = varint (bitmask)
- Field 7 (enclosing_range) = packed varints
- Field 4 (relationships) = length-delimited repeated `Relationship`
- Field 3 (is_implementation) = varint (bool)

## Appendix B: SCIP Symbol Format Quick Reference

```
Format: <language-package> <encoded-package> ... <descriptor-path>
Example: scip-typescript typescript . . src/auth/AuthService#login().  

Segments:
  scip-typescript       Language package identifier
  typescript . .        Encoded package path (language-specific)
  src/auth/             File path descriptor
  AuthService#          Enclosing type (empty for module-level)
  login().              Symbol name + callable marker
  .                     Terminator

Callable markers:
  ().   Function/method (callable)
  #.    Class/struct/interface (not callable)
  .     Variable/constant (not callable)
```
